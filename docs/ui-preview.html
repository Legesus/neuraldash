1. The bolt icon in the activity bar opens the Neuralwatt Energy board — every model, cheapest 7-day-typical first. Row zap icons are tinted by a severity color scale ( ● cheapest green → yellow → ● most expensive red, saturation 45% mid → 85% extremes) computed over log(basis) energy. Grey zap = no live data (flex rows). The collapsible Flex tiers — registry pricing, no live energy data section lists -flex variants from data/models-registry.json (pricing only). Disable either with neuraldash.colorScale / neuraldash.showFlexTiers.
